# 🎨 Pixel Color Picker

**Browser-based pixel color picker with zoom, drag, and color collection board.**

[![MIT License](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)

Upload any image, zoom in to see individual pixels, click to pick exact colors, and build your palette. All processing stays in your browser – no uploads, no privacy concerns.

## ✨ Features

- 📸 Upload JPG, PNG, GIF, WebP – drag & drop or click
- 🔍 Zoom up to 100x with mouse wheel, drag to pan
- 🎯 Move mouse to preview color, click to lock and add to collection
- 🔲 Toggle pixel grid when zoomed in
- 📋 Color collection board – unlimited colors, click swatch to copy HEX
- 🌐 100% local, no server uploads

## 📦 Usage

1. Open `index.html` in any modern browser.
2. Upload an image.
3. Hover to preview, click to pick.
4. Use wheel to zoom, drag to pan.
5. Collect colors and copy values.
